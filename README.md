# ☕ Java — Primeiro Bloco | Generation Brasil

Repositório criado para reunir os **exercícios, práticas e conteúdos desenvolvidos durante o primeiro bloco do Bootcamp Full Stack Java da Generation Brasil**.
Ao longo dessa etapa, foram trabalhados os fundamentos da linguagem Java e, posteriormente, conceitos de **Programação Orientada a Objetos**, com exercícios práticos para consolidar cada conteúdo aprendido.

## 📚 Conteúdos estudados

### ☕ Fundamentos de Java

- Variáveis
- Operadores
- Estruturas condicionais
- Estruturas de repetição
- Arrays
- Collections
- Estruturas de dados
- Métodos

### 💻 Programação Orientada a Objetos

- Encapsulamento
- Programação Orientada a Objetos
- Abstração

### 🛠️ Recursos da linguagem

- Tratamento de exceções
- `Optional`
- Expressões Lambda

## 🎯 Objetivo

O objetivo deste repositório é registrar minha evolução durante o primeiro bloco do Bootcamp, desde os primeiros conceitos da linguagem até a utilização de recursos mais avançados e conceitos de Orientação a Objetos.
Os exercícios foram desenvolvidos de forma progressiva, permitindo aplicar na prática os conteúdos apresentados durante as aulas.

## 🚀 Aprendizado

Este foi o início da minha jornada no desenvolvimento **Full Stack Java**, proporcionando uma base importante para os próximos blocos do bootcamp e para o desenvolvimento de projetos mais completos.
